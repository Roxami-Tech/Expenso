
# Expenso 💜

### Every Expense, Under Control.

Expenso is a modern, minimalist Android expense tracker designed to help users manage their personal finances, track income and expenses, organize budgets, and understand their spending habits.

Built with ❤️ by **Roxami Tech**.

---

## ✨ Features

- 📊 **Dashboard** – View your balance, total income, and expenses.
- 💸 **Transaction Management** – Add and track income and expenses.
- 📂 **Categories** – Organize your financial transactions.
- 🎯 **Budget Management** – Create and monitor spending budgets.
- 📈 **Financial Insights** – Visualize your spending habits.
- 💾 **Local Database** – Store financial data locally using Room.
- 🎨 **Modern UI** – Clean interface with a premium purple theme.
- 💰 **AED Currency** – Financial amounts displayed in UAE Dirhams.

## ⚙️ Requirements

- Android device running Android 9.0 or later
- Android development environment
- JDK 17
- Android SDK 36
- Gradle 8.13 or compatible wrapper
- Internet connection for initial dependency downloads

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Roxami-Tech/Expenso.git
```

### 2. Open the project

Open the cloned project folder in your Android development environment.

### 3. Sync Gradle

Allow Gradle to download the required dependencies.

### 4. Build and Run

Connect an Android device or start an emulator, then build and run the application.

## 🔒 Privacy

Expenso is designed around local data storage.

The current implementation uses a local Room database. Cloud synchronization and account-based features are not currently included.
